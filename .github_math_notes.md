# GitHub Math Rendering Notes

**Date:** 2026-09-23

## Issue
GitHub's MathJax implementation restricts certain LaTeX commands for security reasons.

## Not Supported on GitHub
- `\operatorname{}` - security restriction
- `\boxed{}` - may not render
- `\DeclareMathOperator`
- Some AMS LaTeX packages

## Use Instead
| Don't Use | Use This |
|-----------|----------|
| `\operatorname{Bernoulli}` | `\text{Bernoulli}` |
| `\operatorname{Ber}` | `\text{Ber}` |
| `\operatorname{Corr}` | `\text{Corr}` |
| `\operatorname{Var}` | `\text{Var}` |
| `\boxed{...}` | Just use the content or emphasize differently |

## What Works Fine
- `\text{...}` for text in math mode
- `\sim`, `\overset`, `\mid`, `\perp`
- `\frac{}{}`, subscripts, superscripts
- `\sum`, `\prod`, `\int`
- Greek letters: `\alpha`, `\beta`, etc.
- `\begin{cases}...\end{cases}`
- Basic formatting: `^`, `_`, `{}`, `\left`, `\right`

## Official Documentation
https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions

GitHub uses MathJax with a **restricted subset of LaTeX commands**.

## Fixed in This Project
Replaced 5 instances of `\operatorname{Bernoulli}` with `\text{Bernoulli}` and removed 2 uses of `\boxed{}`.
